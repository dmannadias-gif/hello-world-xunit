# \# hello-world-xunit

# 

# Solução .NET 10 criada via CLI com um projeto de aplicação console e um projeto de testes unitários com xUnit.

# 

# \## Estrutura

# 

# \- \*\*MeuPrimeiroTeste.App\*\*: contém a classe `OlaMundo`, cujo método `ObterMensagem()` retorna `"Hello, World!"`.

# \- \*\*MeuPrimeiroTeste.Tests\*\*: contém a classe `OlaMundoTeste`, que valida o retorno do método com `Assert.Equal()`.

# 

# \## Tecnologias

# 

# \- .NET 10

# \- xUnit

# 

# \## Como executar

# 

# Rodar a aplicação:

# 

# ```bash

# dotnet run --project MeuPrimeiroTeste.App

# ```

# 

# Rodar os testes:

# 

# ```bash

# dotnet test

# ```
